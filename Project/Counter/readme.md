# A Simple Counter App

## Short Description 

A minimal interactive counter application built with **HTML, JavaScript, and Tailwind CSS**.  
Users can **increase, decrease, and reset** the counter value with dynamic color changes based on the number.

---

##  Live Demo
 [Counter app](https://jasmine-kavris.github.io/Revamp-Mernstack/Project/Counter/counterapp.html)  

---

##  Tools & Technologies Used
- **HTML5** – Structure
- **JavaScript (ES6)** – Logic & Event Handling
- **Tailwind CSS** – Styling & Responsive Design
- **Git & GitHub** – Version Control & Hosting

---

##  Features
-  **Increase** counter value  
-  **Decrease** counter value  
-  **Reset** counter to zero  
-  **Dynamic color change**:
  - Green → Positive values  
  - Red → Negative values  
  - Black → Zero
